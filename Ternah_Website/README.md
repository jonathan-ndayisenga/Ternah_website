# Ternah Software Company Ltd — Website

Static multi-page site. Every `.html` file is generated by `build_pages.py`;
never hand-edit the HTML. Edit the script, then run `python build_pages.py`.

## Structure
```
build_pages.py              all content, page templates, sitemap.xml + robots.txt
assets/ternah-ui/           copy of the shared ternah-ui tokens + Hanken Grotesk font
assets/css/styles.css       website styles (uses the tokens; never redefine them)
assets/js/main.js           menu, reveals, contact form, hero switcher, filters
assets/img/                 photos and product screenshots (see below)
tools/make_images.py        regenerates favicon-32.png, apple-touch-icon.png, og-image.png
tools/make_illustrations.py draws the blue product illustrations in assets/img/art/<product>.svg
tools/make_scenes.py        draws the hero scenes (hero-<product>.svg) and article covers (article-<slug>.svg)
```

## Settings (top of build_pages.py)
`SITE_URL`, `EMAIL`, `PHONE`, `WHATSAPP`, `OFFICE`, `COMPANY_REG` (footer),
`FORM_ENDPOINT` (Formspree / Netlify Forms URL; empty = form opens the visitor's
email app), `ANALYTICS_DOMAIN` (Plausible; empty = off).

## Photos and screenshots
Drop files at these paths and rebuild; the drawings are replaced automatically.
- `assets/img/hero/<product-key>.webp` — hero photo, 16:9 (e.g. 1600 x 900), for
  ternah-health and ternah-factories. Keep the people on the left half: the product
  screen covers the right. Update the slide's `alt` in `HERO_SLIDES` to match the photo.
- `assets/img/articles/<slug>.webp` — article cover, 16:9 (e.g. 1200 x 675).
- `assets/img/screens/<product-key>.webp` — 3:2 product screenshot (e.g. 1440 x 960).
  Keys: ternah-health, ternah-factories, mykashop, sacco, property, pharmacy,
  hospitality, queueflow. Until a file exists, Ternah Health and Ternah for
  Factories show an HTML drawing of their home screen; the others show a placeholder.

## Theme
Colours, type and radii come from `assets/ternah-ui/tokens.css`, the same file
Ternah Health and Ternah for Factories use. When ternah-ui changes, copy the new
`tokens.css` and font over this folder's copy. Navy (`--nav`) is the action colour;
amber (`--warn`) is only used for form errors and inside product screenshots.

## Local preview
```
python build_pages.py
python -m http.server 8000
```

## Deploy (Render static site or any static host)
Build command `python build_pages.py`, publish directory `./`.

## Case studies
Ternah Health, Ternah for Factories, Ternah Pharmacy and Pearl Educate each have a case study
(`CASES` in `build_pages.py`), shown as coloured bands under the product grid on the Products page.
Each band takes its product's colours from `theme` (`.case-blue`/`yellow`/`wine`/`ocean` in styles.css).
They describe the type of business, not a named client. Put a client's name in `setting` only once they have agreed.

## Articles
Each Insights article is its own page at `insights/<slug>.html`, built by `article_body()` in
`build_pages.py`. The text sits in the `*_MODAL` blocks (named from when articles opened as pop-ups).
The reading order follows `INSIGHTS`; Previous / Next wrap around, so every article leads on to another.
Pages in `insights/` use `<base href="../">`, so links inside them are written from the site root.
